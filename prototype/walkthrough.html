Prototype guide

Mid-fidelity wireframe, grayscale, built from the project specification. Open it by double-clicking index.html; nothing needs installing.

Start each scenario with a clean demo, so there is no account or saved session left over.

Scenario 1: first-timer, beginner follower

Goal: pick two Saturday beginner workshops and keep them in her own programme with no clashes.

  1. Open Programme.
  2. Set Day = Saturday, Type = Workshop, Level = Beginner, Role focus = Follow. (Shortcut: same filters pre-set.)
  3. Press Save on “Saturday starter: the follower's basics” (09:30).
  4. The site sends you to Log in / Sign up. Sign up with any name, email and demo password.
  5. You return to the session list and the first workshop is saved. Press Save on “Saturday starter: body movement basics” (11:00).
  6. Open My Programme: both sessions are listed and the banner says there are no clashes.

Scenario 2: experienced dancer, evening

Goal: find out which DJ plays the main social tonight and when it ends.

  1. Open Programme.
  2. Set Day = Friday, Type = Social, Day or night = Night, and Venue = Marea Club. (Shortcut: same filters pre-set.)
  3. Open the 22:00 club social. The page shows the DJ and the time range.
  4. Follow the DJ's name to their performer page: it lists the set time and every other set.

Interactive functions in this prototype

  • Programme filters (day, venue, type, level, role, day or night)
  • Search and a name filter on the performers list
  • My Programme with clash warnings and a calendar download
  • Simulated sign-up and login (accounts live in your browser)
